# DoWhileTasks

20 задач на цикл `do...while` на Java.

## Запуск

```bash
javac -encoding UTF-8 DoWhileTasks.java
java DoWhileTasks
```

После запуска введите номер задания (1–20), `0` — выход.

## Список заданий

1. Вывод чисел от 1 до 10
2. Обратный отсчёт от 10 до 1
3. Чётные числа от 2 до 20
4. Нечётные числа от 1 до 19
5. Сумма чисел от 1 до N
6. Таблица умножения
7. Степень числа (без `Math.pow()`)
8. Сумма цифр
9. Количество цифр
10. Переворот числа
11. Факториал
12. Палиндром
13. Поиск максимума (ввод до 0)
14. Поиск минимума (ввод до 0)
15. Положительные и отрицательные
16. Угадай число
17. Пароль (правильный пароль: `java123`)
18. Меню калькулятора
19. Банковский счёт
20. Камень, ножницы, бумага
